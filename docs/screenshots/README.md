# VitaAI 桌面界面画廊

[返回项目介绍](../../README.md)

截图展示现有项目组件。简历分析报告使用内置示例；语音面试与面试报告使用本地临时展示页加载真实组件和虚构数据，不代表真实面试或模型评测结果。临时展示未写入业务数据库，未调用模型或语音服务。

模板仅保留两种代表版式。资料库与编辑器展示空白状态；设置仅截取对话框，账户邮箱与密钥未展示。
